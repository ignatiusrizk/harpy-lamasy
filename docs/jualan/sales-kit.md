## 4. Jawaban Keberatan (objection handling)

| Keberatan | Jawaban |
|---|---|
| "Mahal nggak?" | Trial 14 hari gratis. Setelah itu 1× aktivasi 800rb (selamanya, bukan per tahun) + bayar per pakai. 300 order/bulan ≈ Rp 15-45rb/bulan. Bandingkan langganan 200-500rb/bulan. |
| "Sudah pakai Smartlink" | Bagus, berarti udah terbiasa. LAMASY per notanya setengahnya (50 vs 100), QRIS tanpa potongan 1%, plus AI briefing & laporan akuntansi yang di sana nggak ada. Pindah gampang: AI import baca Excel export lama, ±1 jam. Trial dulu, jalan paralel, nggak ada risiko. |
| "Ribet nggak setupnya?" | 5 menit: daftar → centang layanan + isi harga (sudah ada template) → buat order pertama. Ada panduan langkah-demi-langkah + tur sistem otomatis. Data pelanggan lama tinggal upload Excel. |
| "Karyawan saya gaptek" | Kasirnya dibuat sesederhana mungkin, bahasa Indonesia semua, bisa dipakai dari HP. Ada mode suara juga: sebut aja ordernya, AI yang isi form. |
| "Takut data hilang / kekunci" | Data bisa di-export Excel/PDF kapan pun, tanpa kontrak. Kalau berhenti, data tetap milikmu. |
| "Nanti kalau sepi rugi dong bayar sistem" | Justru itu kelebihannya: bayar per pakai. Sepi = biaya turun sendiri. Nggak ada biaya bulanan tetap. |
| "QRIS-nya potong berapa?" | 0%. Kamu upload QRIS milikmu sendiri, pembayaran langsung masuk rekeningmu, kami nggak megang uangmu sama sekali. |
