# Invoice B2B Enhancement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah PPN opsional + nomor invoice formal (INV/YYYY/MM/000N) ke fitur invoice B2B yang sudah ada (`StrukGenerator::generateInvoice`).

**Architecture:** Enhancement, bukan build baru. 2 kolom di hl_piutang (invoice_no, pajak_persen). mark_invoiced generate nomor formal + simpan PPN. generateInvoice pakai nomor formal + hitung PPN. renderPdf render baris PPN. Zero regression untuk retail nota + invoice existing (PPN=0 → behavior lama).

**Tech Stack:** PHP 8 vanilla, MariaDB (Hostinger), existing StrukGenerator render pattern.

## Global Constraints

- **Schema:** `invoice_no VARCHAR(40) NULL`, `pajak_persen DECIMAL(5,2) NOT NULL DEFAULT 0`
- **Invoice number format:** `INV/YYYY/MM/000N` — counter per tenant per bulan, immutable setelah generate
- **PPN clamp:** 0–100 server-side
- **Backward compat:** PPN=0 → tidak ada baris PPN, total = total_tagihan (behavior existing). Retail nota tidak terpengaruh.
- **Tenant scope:** existing query di generateInvoice + mark_invoiced sudah WHERE tenant_id+outlet_id — pertahankan
- **mysql client:** /opt/homebrew/opt/mysql-client/bin/mysql (~/.my.cnf prod)
- **No new file** — edit piutang.php + core/StrukGenerator.php saja
- **Smoke test** (no unit test framework): DB query + browser render

- [ ] **Step 3: Add generateInvoiceNo() helper di piutang.php**

Di piutang.php, setelah baris `$db = Database::get();` (sekitar line 19), tambah fungsi helper (sebelum blok `if ($action === ...`):

```php
function generateInvoiceNo(PDO $db, int $tid): string {
    $ym = date('Y/m');
    $prefix = "INV/$ym/";
    $stmt = $db->prepare("SELECT COUNT(*) FROM hl_piutang
                          WHERE tenant_id=? AND invoice_no LIKE ?");
    $stmt->execute([$tid, $prefix . '%']);
    $next = (int)$stmt->fetchColumn() + 1;
    return $prefix . str_pad((string)$next, 4, '0', STR_PAD_LEFT);
}
```

- [ ] **Step 6: Update markInvoiced() JS untuk kirim PPN**

Di piutang.php markInvoiced (~line 646), ganti confirm + body:

```javascript
async function markInvoiced(id){
  const pajakStr = prompt('PPN (%) untuk invoice ini?\n\nKosongkan atau 0 = tanpa PPN.\nContoh: 11 untuk PPN 11%', '0');
  if (pajakStr === null) return; // batal
  const pajak = Math.max(0, Math.min(100, parseFloat(pajakStr) || 0));
  if (!confirm('Tandai sebagai sudah tagih? (deduct 200 coin + buka WA invoice)')) return;
  try {
    const r = await fetch('piutang.php?action=mark_invoiced', {method:'POST', headers:{'Content-Type':'application/json','X-CSRF-Token':CSRF}, body:JSON.stringify({id, pajak_persen: pajak})});
    const d = await r.json();
    if (d.error){ alert('⚠️ '+d.error); return; }
    if (d.wa) window.open(d.wa, '_blank');
    showToast('✅ Invoice ditandai terkirim','success'); loadList();
  } catch(e){ alert('Gagal: '+e.message); }
}
```

(Pakai `prompt()` minimal — tidak bikin modal baru. Cukup untuk MVP.)
